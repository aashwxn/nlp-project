About

DocuMind AI reads your document, extracts its text locally, and uses the Groq API to summarize it, pull out key information, explain it simply, and answer your questions.

Files are stored temporarily on this computer only and deleted when you remove them. No database, no login. Built with Flask, HTML, CSS and JavaScript.
